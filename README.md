# Trabalho de Grafos 🔗

Trabalho acadêmico de implementação de um **grafo** em C# (.NET), com leitura de vértices e arestas ponderadas via console e um desafio aplicado.

## 📋 Sobre

O programa permite construir um grafo informando a quantidade de vértices e arestas, o vértice de origem, o de destino e o peso de cada aresta. A estrutura é modelada em classes separadas.

## 🗂️ Estrutura

```
Trabalho_Grafos/
├── Program.cs     # menu / entrada de dados e montagem do grafo
├── Grafo.cs       # representação do grafo e suas operações
├── Aresta.cs      # modelo de aresta (origem, destino, peso)
└── Desafio.cs     # resolução do desafio proposto
```

## ▶️ Como executar

Requer o [.NET SDK](https://dotnet.microsoft.com/download).

```bash
cd Trabalho_Grafos/Trabalho_Grafos
dotnet run
```

Ou abra a solução `Trabalho_Grafos.sln` no Visual Studio e execute.
